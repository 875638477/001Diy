# 名词解释

## NAS

NAS 是 Network Attached Storage，网络附属存储。它是一台一直开着、专门放文件的小电脑。硬盘插在它身上，其他设备通过网络读写这些文件。

自己用主板和硬盘装的文件服务器，也是一台 NAS。说「我的 NAS」时，指的是这台存文件的机器，不是某一个软件。

## 群晖

群晖是 Synology 的中文品牌名，一家做 NAS 的公司。说「群晖」通常就是指群晖出品的那台整机。

它和自己组装的差别主要在系统。群晖预装 DSM，用浏览器打开就能建共享文件夹、加用户、装网盘和相册。DSM 的使用许可只覆盖群晖原装机器。

常用套件：

- Synology Drive：类似网盘，可按需下载。
- File Station：在网页里看文件。
- VPN Server：可以做 WireGuard 服务端。没有公网 IP 时，群晖仍要主动连到外面的云服务器，不能只在家里监听。

## 黑群晖

黑群晖是社区叫法：把群晖的 DSM 装到自己组装的电脑上，让普通机器看起来像一台群晖。引导程序会伪装成群晖硬件，从而通过系统的硬件检查。

这样用的结果：

- 套件中心、QuickConnect、系统升级没有官方支持，一次升级就可能开不了机。
- 不在群晖保修范围内。
- 数据盘和系统盘绑在一套非官方引导上，出问题后恢复困难。

自己组装时，安装 Ubuntu、TrueNAS Scale 或 OpenMediaVault。这三份记录里的操作步骤按 Ubuntu 来写。

## Tailscale

Tailscale 是装在手机、电脑、服务器上的虚拟组网软件，底层用 WireGuard 加密。每台设备登录同一个账号后，会得到一个 `100.` 开头的地址，彼此可以直接通信。

它不存文件。文件仍在家里的硬盘上。它只负责让外面的手机找到家里的服务器，一般不用在路由器上做端口映射。

账号要开双重验证。

## 公网 IPv4

IPv4 是一串像 `47.96.12.34` 这样的地址。「带一个公网 IPv4」意思是：互联网上的其他人可以拿这个地址直接找到这台机器。

内网地址只能在局域网或运营商内部使用，外面找不到。常见内网段：

- `10.` 开头
- `100.64.` 到 `100.127.` 开头（运营商大内网，CGNAT）
- `172.16.` 到 `172.31.` 开头
- `192.168.` 开头

自己组装主机、插上网线，都不会自动得到公网 IPv4。地址由手机卡所属运营商，或云服务器厂商分配。

## 云服务器和家里的主机

这是两台机器：

- 家里自己装的那台，插在中兴路由器上，负责存文件。
- 向阿里云、腾讯云租的轻量云服务器，在厂商机房里，自带公网 IPv4。家里的服务器主动连上去，别人访问云上的那个地址。

云服务器按月租，不用自己买主板和硬盘。

## 龙猫会员

龙猫云会员是一份代理节点的流量订阅。导入客户端后，设备可以借用他们的节点出去上网。节点是对方的机器。

这份会员不能当作中转云服务器：不能在节点上装 WireGuard、开端口，也不能把家里的文件服务转到那个 IP。把订阅装到自己的云服务器上，也只是让云服务器上网时走龙猫的节点，外面的人仍然访问不到家里的硬盘。

龙猫会员留在手机或电脑上做原来的用途。文件中转需要另外租一台能用 SSH 登录、带公网 IPv4 的云服务器。
