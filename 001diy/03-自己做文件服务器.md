# 自己做文件服务器

一台一直开着的小主机，插上数据硬盘，装下面其中一个系统。

| 系统 | 适合 |
|---|---|
| Ubuntu Server | 愿意用命令，只要共享文件夹和远程下载 |
| TrueNAS Scale | 想用网页管磁盘、共享和快照 |
| OpenMediaVault | 轻量网页界面，老机器也跑得动 |

下面是 Ubuntu 上的做法。数据盘挂到 `/srv/disk`。Samba 给同一局域网，SFTP 给外面的手机。

## 安装

```bash
sudo apt update
sudo apt install -y samba openssh-server
sudo smbpasswd -a 你的用户名
```

`/etc/samba/smb.conf` 末尾加上：

```ini
[data]
   path = /srv/disk
   browseable = yes
   read only = no
   valid users = 你的用户名
```

然后执行：

```bash
sudo systemctl restart smbd
```

地点 B 和这台服务器在同一局域网时，电脑访问服务器的 `192.168.x.x`，共享名是 `data`。

## 防火墙

只允许这些来源访问 `22` 和 `445`：

- 家里的局域网，例如 `192.168.0.0/24` 或 `192.168.1.0/24`，以路由器实际网段为准
- Tailscale 的 `100.64.0.0/10`
- WireGuard 的 `10.8.0.0/24`

公网网卡上不要放行 `445`。

## 手机怎么连

文件管理器用 Solid Explorer 或 CX。

- 在家：SMB，主机填 `192.168.x.x`，共享名 `data`。
- 在外面：先连上 Tailscale 或 WireGuard，再新建 SFTP，主机填 `100.x` 或 `10.8.0.2`，端口 `22`，用户是这台 Linux 上的用户。

## 群晖原装机器

如果地点 C 是群晖原装 NAS：

1. 控制面板里建共享文件夹并设用户权限。
2. 套件中心安装 Synology Drive，把该文件夹启用。
3. 手机和电脑安装 Synology Drive。在家填局域网 IP；在外面填 `100.x` 或 `10.8.0.2`。
4. 管理员开启双重验证。

Drive 会按需下载，比手机上直接挂 SMB 适合 4G/5G。
