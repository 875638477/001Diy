# 外网怎么连回来

家庭 5G 出口多数没有公网 IPv4，在中兴路由器上做端口映射往往没有用。服务器主动向外建立一条加密连接，手机再进入同一条通道，就能读到硬盘。

先做 [05-公网IPv4与5G路由器.md](05-公网IPv4与5G路由器.md) 里的检查。已经有公网 IPv4 时，可以在中兴上做端口映射，只映射 SFTP 的 `22`。没有公网 IPv4 时，用下面两条路之一。

## 方案一：Tailscale

网络能够连上 Tailscale 时用这条，不用自己租服务器。

地点 C（Ubuntu）：

```bash
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
tailscale ip -4
```

记下输出的 `100.x.x.x`。

- 地点 A、地点 B 的电脑：安装 Tailscale，登录同一个账号。
- 安卓：安装 Tailscale，登录后保持连接。
- 群晖原装机：套件中心安装 Tailscale，用同一个账号登录。

外面的手机用 SFTP 或 Synology Drive，主机填这个 `100.x`。人在地点 B 的局域网时，关掉这条通道，改用 `192.168.x.x`。

## 方案二：云服务器加 WireGuard

Tailscale 连不上或很慢时用这条。云服务器要有公网 IPv4，系统用 Ubuntu。规格和价格见 [06-云服务器.md](06-云服务器.md)。安全组放行 UDP `51820`。

家里的文件服务器主动连到云服务器，这样中兴路由器不需要公网 IP，也不用做端口映射。

### 云服务器

```bash
sudo apt update && sudo apt install -y wireguard
wg genkey | tee /etc/wireguard/server.key | wg pubkey > /etc/wireguard/server.pub
```

`/etc/wireguard/wg0.conf`：

```ini
[Interface]
Address = 10.8.0.1/24
ListenPort = 51820
PrivateKey = <server.key 的内容>
# 换成云服务器实际的外网网卡名，常见是 eth0 或 ens3
PostUp = sysctl -w net.ipv4.ip_forward=1; iptables -A FORWARD -i wg0 -j ACCEPT; iptables -A FORWARD -o wg0 -j ACCEPT
PostDown = iptables -D FORWARD -i wg0 -j ACCEPT; iptables -D FORWARD -o wg0 -j ACCEPT

# 家里的文件服务器
[Peer]
PublicKey = <地点C的公钥>
AllowedIPs = 10.8.0.2/32

# 安卓
[Peer]
PublicKey = <手机的公钥>
AllowedIPs = 10.8.0.3/32

# 地点 A 的电脑
[Peer]
PublicKey = <地点A的公钥>
AllowedIPs = 10.8.0.4/32
```

```bash
sudo systemctl enable --now wg-quick@wg0
```

### 家里的文件服务器

```bash
wg genkey | tee private.key | wg pubkey > public.key
```

`/etc/wireguard/wg0.conf`：

```ini
[Interface]
Address = 10.8.0.2/24
PrivateKey = <地点C的私钥>

[Peer]
PublicKey = <云服务器的公钥>
Endpoint = <云服务器公网IP>:51820
AllowedIPs = 10.8.0.0/24
PersistentKeepalive = 25
```

```bash
sudo systemctl enable --now wg-quick@wg0
```

`PersistentKeepalive = 25` 让家里每隔 25 秒向外打一个包，运营商的 NAT 映射不容易断。

### 安卓

安装官方 WireGuard。新建隧道：

- 地址：`10.8.0.3/32`
- 对端：云服务器公网 IP，端口 `51820`
- AllowedIPs：`10.8.0.0/24`

AllowedIPs 只填这一段时，访问文件服务器的流量进隧道，普通上网仍走 4G/5G。把手机公钥贴回云服务器对应的 `[Peer]`。

手机或地点 A 的 SFTP 主机填 `10.8.0.2`。地点 B 在同一局域网时仍填 `192.168.x.x`，不用开 WireGuard。

## 怎样算通了

1. 手机关掉 Wi-Fi，只留 4G/5G，打开 Tailscale 或 WireGuard。
2. 用 SFTP 从家里的硬盘下载一个文件，能下完即通。
3. 手机连上地点 B 的 Wi-Fi，关掉虚拟网，改用 `192.168.x.x` 再下一份，速度应接近局域网。
4. 用手机流量直接访问家里出口的公网地址加端口 `445`，应当失败。失败才说明硬盘共享没有裸露在公网上。
