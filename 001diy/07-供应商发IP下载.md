# 供应商发一个 IP 就能下载

芯片供应商给一个 IP 就能下文件，用的是公网上的文件服务。对方的电脑或云服务器有公网 IPv4，路由器把端口转到内部的 FTP 或网页目录。密码就是这个服务的登录账号。

## 常见两种

**FTP。** 小供应商最常见。对方说「IP 加用户名密码，用 FileZilla」，端口一般是 `21`。看到的是服务器上的一个文件夹，账号决定能看哪些目录。软件多用 FileZilla Server、Serv-U，或群晖自带的 FTP。

**HTTP 目录。** 把 IP 贴进浏览器就出现文件列表。服务器是 Nginx、IIS，或 HFS。浏览器弹出用户名密码时，那是网页的 Basic 认证。

| 对方怎么给 | 实际协议 |
|---|---|
| IP，端口 21，用 FTP 客户端 | FTP |
| 浏览器打开 IP 就是文件列表 | HTTP |
| 端口 22，要用户名密码 | SFTP |
| `\\IP\共享名` | Windows 共享 SMB |
| 端口 5000，出现群晖登录页 | 群晖网页，再进 File Station |

## 他们能这样做的原因

供应商的宽带或云服务器有公网 IPv4，并且防火墙上放行了 `21` 或 `80`。文件一直放在那台机器上。

家里的中兴 5G 如果没有公网 IPv4，别人用家里的地址加端口是连不进来的。要做出「发给别人一个地址」的效果：

- 宽带或 5G 卡已经有公网 IPv4：路由器把外网端口转到文件服务器。要密码就给每个使用者建账号。
- 没有公网 IPv4：用 [06-云服务器.md](06-云服务器.md) 里的云服务器。发给别人的是云服务器的公网 IPv4。

给外人用时，用带账号的 HTTPS 或 SFTP。FTP 和「浏览器打开 IP 就能下」是对方图省事的做法，账号和文件在网络上明文传输。
