## 先看结论

1. 自己组装的主机负责存文件。它插在中兴 5G 路由器后面。
2. 公网 IPv4 不是组装电脑得到的，是运营商或云厂商分配的互联网地址。
3. 插手机卡的中兴 5G 路由器默认通常没有公网 IPv4，外面的手机无法直接连进来。
4. 先按 [05-公网IPv4与5G路由器.md](05-公网IPv4与5G路由器.md) 核对。两个地址相同且不是内网段，才算有公网 IPv4。
5. 没有公网 IPv4 时，另租一台带公网 IPv4 的轻量云服务器做中转。家里的文件服务器主动连出去。
6. 龙猫会员是代理节点流量，不能当作这台云服务器。
7. 同一局域网里直接用 `192.168.x.x`。人在外面再用虚拟网地址或云服务器地址。
8. 文件端口不要直接暴露在公网。SMB 的 `445` 只给局域网用。
