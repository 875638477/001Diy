# 使用场景

目标：随时从外面拿到地点 C 上硬盘里的文件。地点 C 可以是自己组装的文件服务器、NAS，或群晖原装机器。

## 地点关系

```
地点 A 电脑 ──外网──┐
安卓 4G/5G ──外网──┼── 加密通道 ──► 地点 C（文件服务器）
地点 B ────────────┘                    ▲
   │ 人在家里时走局域网                    │
   └──────── 与地点 C 同一局域网 ─────────┘
```

- 地点 C：部署服务器的地方，硬盘在这里。
- 地点 B：和地点 C 在同一个局域网。人在家时走内网，速度按局域网计算。
- 地点 A：另一处的电脑，只能走外网。
- 安卓手机用 4G/5G 时，和地点 A 一样走外网。

当前出口是中兴 5G 路由器，里面插着手机卡，靠 5G 信号上网。

## 访问时用哪个地址

| 人在哪里 | 主机地址 |
|---|---|
| 地点 B，连着家里的 Wi-Fi | 文件服务器的局域网 IP，例如 `192.168.x.x` |
| 地点 A，或手机只开流量 | Tailscale 的 `100.x.x.x`，或 WireGuard 的 `10.8.0.2` |
| 用云服务器做网页下载 | 云服务器的公网 IPv4 |

同一局域网里优先用局域网 IP，少绕一跳。

## 协议怎么选

- 家里电脑临时拷文件：Samba，端口 `445`。
- 手机和外面的电脑：SFTP（端口 `22`）或同步盘。群晖用 Synology Drive，按需下载。
- 4G/5G 上直接把 Samba 当成本地磁盘会卡。SMB 来回次数多，移动网络延迟高。

## 不要做的事

公网网卡上不要开放 `445`。芯片供应商那种「浏览器打开 IP 就能下」或明文 FTP，账号和文件都在网上裸奔。自己用带登录的 SFTP，或只在加密通道里开放服务。
