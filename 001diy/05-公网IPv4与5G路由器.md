# 公网 IPv4 与中兴 5G 路由器

公网 IPv4 由手机卡所属运营商分配。在中兴后台里改一项普通设置，变不出公网地址。

## 怎么查看

手机或电脑连上这台中兴的 Wi-Fi，对比两个 IP。

### 1. 路由器拿到的地址

打开管理页。中兴常见地址是 `192.168.0.1`、`192.168.1.1` 或 `192.168.8.1`，账号密码在机身贴纸上。

进「状态」「设备信息」或「网络信息」，找到 **IPv4**、**WAN IP** 或 **PDP 地址**，记下来。

不确定管理页地址时：

- 电脑按 `Win + R`，输入 `cmd`，再输入 `ipconfig`，看「默认网关」。
- 手机在 Wi-Fi 详情里看「网关」。

### 2. 外面看到的地址

同一部手机或电脑打开 https://ip.sb ，记下页面上的 IPv4。

### 3. 对照

两个地址相同，并且不是下面这些，就是公网 IPv4：

- `10.` 开头
- `100.64.` 到 `100.127.` 开头
- `172.16.` 到 `172.31.` 开头
- `192.168.` 开头

管理页是 `10.x` 或 `100.64.x`，而 ip.sb 上是另一个地址，就是运营商大内网。两个地址不同，同样说明中间还隔着一层运营商的网络。这两种情况外面都连不进来。

管理页里如果已有 `240` 开头的 IPv6，说明 IPv4 仍可能是内网，IPv6 有机会是公网。手机自己的 4G/5G 也要有 IPv6，中兴的 IPv6 防火墙还要放行对应端口。IPv6 前缀会变，需要动态域名。个人传文件仍以「云服务器上的公网 IPv4」更省事。

## 想向运营商申请

打这张卡所属运营商的客服，说明卡插在 5G CPE 上，要办「动态公网 IP」。普通打电话的套餐经常办不了，物联网卡或政企卡更常见。

各地产品不一样，常见是：

- 给现有的卡加「公网 IP」功能，按月收费，地址还会变。
- 换一张物联网卡或政企卡，套餐里带动态公网 IP，或更贵的固定公网 IP。

办好后，客服会说明要不要改 APN。要改的话，在中兴里找「APN 设置」或「接入点」，填他们给的名称，保存后重启，再按上面的方法核对 WAN IP。

拿到动态公网 IP 之后：

- 文件服务器上装 DDNS 客户端，把当时的地址绑到一个固定域名。
- 在中兴里做端口映射，外网端口转到文件服务器的内网 IP。
- 只映射 SFTP 的 `22`，或网页下载用的端口。不要映射 `445`。

运营商拒绝是常见结果。拒绝之后，中兴继续只负责上网，文件访问改走 [06-云服务器.md](06-云服务器.md) 里的轻量云服务器。
