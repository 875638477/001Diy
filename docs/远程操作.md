# 远程操作：人在家里，电源在公司

局域网网页只在 ESP32 和手机连着同一个路由器时有效。家里的浏览器打不开公司里的 `http://psu.local/`，`psu.local` 这种名字也不会穿过两段不同的网络。

ESP32 上的网页、`/api/state`、`/api/set` 和 Modbus TCP 502 保持不变，仍然只监听公司局域网。远程要解决的是：家里的手机怎么走到公司里的这个地址。

## 采用的做法

公司工位放一台和 ESP32 同一局域网、可以一直开着的设备，跑 [Tailscale](https://tailscale.com/)。它只把电源这一台的 IP 公布到你的虚拟网里。家里的手机和电脑也登录同一个 Tailscale 账号，然后用公司局域网里的那个 IP 打开原来的网页。

```
家里的手机 ── Tailscale ── 公司里的中转设备 ── 公司局域网 ── ESP32 网页 / 502
```

中转设备可以是工位上的电脑、一台软路由，或树莓派。ESP32 固件不用为远程再写一套协议，也不需要对公网开放端口。

官方说明：<https://tailscale.com/docs/features/subnet-routers>

### 公司侧

1. ESP32 连上公司 Wi-Fi，在面板或串口日志里确认它的地址，例如 `192.168.8.50`。公司网若用 DHCP，在路由器里把这个地址绑定给 ESP32 的 MAC，避免下次开机变掉。
2. 在中转设备上安装 Tailscale 并登录。
3. 只宣告电源这一台，不要宣告整段公司网：

```bash
tailscale set --advertise-routes=192.168.8.50/32
```

4. 在 Tailscale 管理页里批准这条路由。账号里开启这台设备的子网路由。
5. 中转设备要能主动访问外网。Tailscale 的协调服务和中继常用 TCP 443。公司防火墙挡住所有对外连接时，这条路不通。

### 家里

1. 手机和电脑安装 Tailscale，登录同一个账号。
2. 浏览器打开 `http://192.168.8.50/`。页面仍是原来的电压、电流和输出开关。
3. 电脑上的 Modbus TCP 连 `192.168.8.50`，端口 502，从机地址 `0x01`。
4. 远程时不要用 `psu.local`。这个名字只在公司当地的局域网里有效。

家里看到的页面和在公司工位上打开的是同一个 ESP32 服务。设定值仍然写到电源主控的 Modbus 寄存器。

## 公司不允许另放中转设备时

让 ESP32-S3 自己加入 Tailscale。官方客户端没有 ESP32 版本。社区里能在 ESP32-S3 上跑协议栈的工程：

| 工程 | 链接 | 说明 |
|---|---|---|
| MicroLink | <https://github.com/Csontikka/microlink> | 面向 ESP32 的 Tailscale 客户端。说明里建议 ESP32-S3 带 PSRAM |
| tailscale-mpe-rust | <https://github.com/punnerud/tailscale-mpe-rust> | 用 Rust 写的 ESP32-S3 客户端，含一个隧道内的网页 demo |

家里的手机仍用 Tailscale 官方客户端。连上之后打开的是这台 ESP32 在虚拟网里的地址（`100.x.x.x` 或 MagicDNS 名字），不是 `psu.local`。

这两个仓库只负责把 ESP32 接进虚拟网，里面没有电源寄存器和 `/api/set`。网页仍按 [联网方案](联网方案.md) 里的官方示例来做，再和这里的客户端放进同一个固件。公司网络同样要允许这块板向外连接。

经典 ESP32 上的 WireGuard 组件是 <https://components.espressif.com/components/trombik/esp_wireguard>。它列出的目标是 ESP32、ESP32-S2、ESP32-C3 和 ESP8266，当前不作为 ESP32-S3 的做法。

## 现场约束

人在家里，输出端在公司，旁边可能有人接线。远程可以改电压、电流设定并读回状态。打开输出前，公司现场要先在面板上给出允许；允许位未置位时，从机拒绝 `ONOFF = 1`。保护门限、过压和过流仍只在电源主控里执行。

Tailscale 账号只加自己的手机和电脑。不要把 80 和 502 映射到公司的公网地址上。
