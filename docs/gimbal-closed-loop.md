# 云台无刷电机闭环记录

直流无刷云台采用同一套级联结构：内环负责电机换相和力矩，外环用相机上的 IMU 把相机稳定在惯性空间里。内环角度有两种来源，本记录把两种方案都写完整。

- 方案一：线性霍尔测角 + IMU 外环
- 方案二：磁编码器测角 + IMU 外环

两套方案的电流环、IMU 姿态环、角速度环、跟随逻辑和调试顺序相同。差别在角度传感器的安装、解算、标定，以及上电时能不能得到唯一的机械绝对角。

每台装出来的云台，把实测参数填进文末的[单台记录表](#9-单台记录表)。

---

## 1. 控制目标与回路分工

云台要同时满足两件事：

1. 电机在零速附近仍能输出平滑力矩。云台电机长时间堵转或极低速运行，反电动势接近零，无感观测器在这里没有可用信号。换相角必须来自角度传感器。
2. 相机相对惯性空间保持姿态。底座（手柄、机架）在动，关节角不变时相机仍会跟着转。只有装在相机侧、位于三轴电机之后的 IMU 能看到这个转动。

回路分工：

| 回路 | 传感器 | 输出 | 典型速率 |
| --- | --- | --- | --- |
| 电流环 | 相电流采样 | 电压矢量（SVPWM） | 10–20 kHz，与 PWM 同步 |
| 换相角 | 线性霍尔或磁编 | 电角度 θe | 与电流环同拍 |
| 角速度环 | 相机 IMU 陀螺 | 力矩电流 Iq_ref | 1 kHz |
| 姿态角环 | 加速度计修正后的姿态 | 角速度给定 ω_cmd | 200–500 Hz |
| 跟随（主要是航向） | 底座 IMU 或关节机械角 | 缓慢的角度给定 | 50–200 Hz |

力矩方向的约定（两套方案相同）：

- 电角度 θe 增大的方向定义为电机正方向。
- 正的 Iq 产生使 θe 增大的力矩。
- 相机陀螺绕该机械轴的正角速度，应由负的 Iq 抵消。符号在装机时一次标定，写入记录表，之后不再改相序。

## 2. 共用功率与电流环

两套方案共用这一层。角度传感器只提供 θe，不改变电流环形式。

### 2.1 功率级

- 三相全桥，PWM 20–40 kHz，中心对齐，以便在 PWM 中点采样电流和线性霍尔。
- 母线电压按电机额定选取。小相机云台常见 7.4–12 V。
- 电流采样用两相或三相低侧/内联分流。标度写成 A/count，极性按“正电流流出逆变器、流入电机 A 相”统一。
- 电机星形连接时，相电阻 R、相电感 L 由线线测量值除以 2 得到。

测量：

- 线电阻 R_ll 用毫欧表，相电阻 `R = R_ll / 2`。
- 线电感 L_ll 用 LCR，1 kHz，相电感 `L = L_ll / 2`。
- 极对数 Npp：匀速转过一整圈机械角，数线性霍尔电周期个数；磁编则看 `Δθe / Δθm`。

### 2.2 FOC

Id 给定为 0。云台转速极低，反电动势解耦项可以略去，需要时再加 `ωe * L * Iq`。

```text
θe        来自方案一或方案二
Iα, Iβ    = Clarke(Ia, Ib, Ic)
Id, Iq    = Park(Iα, Iβ, θe)

Id_ref    = 0
Iq_ref    = 来自角速度环，并做限幅（不超过电机持续电流）

Vd        = PI_d(Id_ref - Id)
Vq        = PI_q(Iq_ref - Iq)

Vα, Vβ    = InvPark(Vd, Vq, θe)
SVPWM(Vα, Vβ, Vbus)
```

电流 PI 初值按期望带宽 ωc 计算，再上机微调：

```text
Kp = ωc * L
Ki = ωc * R
```

ωc 取电流采样率的 1/10 左右。20 kHz 采样时，先试 1 kHz（ωc ≈ 6280 rad/s）。积分做抗饱和：输出顶到母线电压圆时停止积分继续累加。

没有电流采样时，可以用同一 θe 做电压正弦换相：角速度环的输出直接当 Vq，Vd = 0。零速力矩仍可用，电流不再受闭环约束，限幅必须更保守。有分流电阻时按电流环来做。

### 2.3 电角度偏移标定

相序定好之后做一次，两套方案通用。标定期间不要把传感器角放进 Park，强制使用一个已知的定子电角度。

1. 固定施加定子电角度 0 的电流矢量：`Ia = I_align`，`Ib = Ic = -I_align / 2`。`I_align` 取持续电流的 30%–50%，保持约 0.5 s，转子会被拉到该矢量方向。
2. 在转子静止时读传感器。
   - 线性霍尔直接得到电角度读数 θe_raw，令 `θe_offset = θe_raw`。
   - 磁编得到机械角 θm，令 `θe_offset = wrap(Npp * θm)`。
3. 此后 `θe = wrap(θe_sensor - θe_offset)`。
4. 验证：给一个小的正 Iq，θe 的解绕值应持续增加。若减小，对调任意两根电机相线，然后从头重做第 1–3 步。相序和偏移必须成对记录。

`wrap` 把角度折回 `[0, 2π)`。

## 3. 方案一：线性霍尔内环 + IMU 外环

线性霍尔输出与磁场分量成正比的模拟电压。用两路正交分量做 `atan2` 得到角度。它测的是磁场方向，适合零速换相。

### 3.1 两种安装，信息量不同

**安装 H1：霍尔对着电机转子磁钢（读泄漏磁场）**

- 直接得到电角度，FOC 可以马上用。
- 一对极转过一次，信号走完一个电周期。上电瞬间的机械绝对角只能确定到 `360° / Npp` 的一个格子里。
- 运行中对电角度连续解绕，可以累计机械角：`θm = θe_unwrapped / Npp`。这是本段上电之后的相对机械角，断电即丢失格子编号。
- 俯仰、横滚行程通常大于一个极距，因此不能靠上电时的一次 `atan2` 判断关节在哪。关节限位和回中要先找机械零点（顶到限位、或借助 IMU 重力），再开始解绕。

**安装 H2：轴端单独粘一颗径向充磁（一个极对）磁铁，两颗线性霍尔读这颗磁铁**

- `atan2` 得到的是机械绝对角 θm，一圈内唯一。
- 电角度由机械角推出来：`θe = wrap(Npp * θm - θe_offset)`。
- 和磁编的信息等价，解算、温漂和正交误差要自己处理。磁编芯片内部已经做了这些补偿。

云台三个轴都需要关节限位或上电就知道朝向时，用 H2。只要求零速力矩平滑、关节零点靠 IMU 或机械挡块来找时，用 H1。

下面按两路正交模拟量来写。H1 的 `atan2` 结果是电角度，H2 的 `atan2` 结果是机械角，偏移公式用第 2.3 节对应的那一种。

### 3.2 器件与电路

- 线性霍尔：比例型，例如 DRV5055 一类。灵敏度按磁铁气隙下的峰峰值来选，静态输出落在 ADC 量程中部，转一圈不饱和。
- 两颗霍尔在磁铁圆周上相差 90° 机械角（H2）。H1 则按电角度相差 90° 放置，间距等于极距的 1/4。
- 模拟前端：靠近霍尔做 RC 低通。云台机械角速度很少超过 180°/s，14 对极时电频率大约 7 Hz，传感器带宽不紧张。低通用来压 PWM 串扰，截止频率 1–5 kHz 即可。截止过低会在快速摇摄时带来电角度滞后和力矩纹波。
- ADC 与电流采样同一时刻，取 PWM 中心，避开开关沿。12 位及以上。

### 3.3 角度解算

原始量 `ax`、`ay` 为两路 ADC。

离线标定得到每路的偏置和幅度（见 3.4）：

```text
x = (ax - offset_x) / gain_x
y = (ay - offset_y) / gain_y
θ = atan2(y, x)
```

两路不完全正交或幅度仍有残余误差时，李萨如图是椭圆。用慢速转过的一整圈数据做一次椭圆校正（把椭圆拉回单位圆）再 `atan2`。校正矩阵和偏置一起写入记录表。

H1：`θe_sensor = θ`，机械累计角 `θm += wrap_pi(θ - θ_prev) / Npp`。
H2：`θm = θ`，`θe = wrap(Npp * θm - θe_offset)`。

任一通道顶到 ADC 满量程时，本拍角度作废，沿用上一拍，连续数拍则停机。饱和时 `atan2` 会给出错误扇区，电流环会冲击。

### 3.4 线性霍尔标定

在偏移标定（第 2.3 节）之前先做幅值和偏置，否则电角度偏移会被偏置误差带偏。

1. 电机开环慢转，或用手匀速拨过至少两个电周期（H1）或一整圈机械角（H2）。记录两路 ADC。
2. `offset = (max + min) / 2`，`gain = (max - min) / 2`。两路 gain 归一化后幅度应接近。
3. 画 x–y。轨迹应接近圆。呈椭圆就做椭圆校正，直到半径变化小于约 5%。
4. 再做第 2.3 节的电角度对齐。
5. 温度变化大时偏置会漂。停机且确认附近没有新的铁磁物体后，可重复步骤 1–2。零速悬停期间不要在线改偏置：静止时偏置和真实角度混在一起，分不开。

### 3.5 和 IMU 外环的接口

线性霍尔方案交给外环的量只有两个：

- 每拍的 θe，供电流环换相。
- 机械角 θm。H2 上电即绝对有效。H1 在完成找零之前只标记为“相对角，禁止做关节限位以外的位置控制”。

外环不读取霍尔的原始 ADC。角速度反馈来自陀螺，不用霍尔微分当稳定环的速度反馈。霍尔微分噪声大，放进角速度环会让电机发嘶声。

### 3.6 本方案的使用边界

适合：

- 电机本身带线性霍尔板，或轴端已经留了磁铁位置、希望少一颗编码器芯片。
- 可以接受一次椭圆标定，并在记录表里留下偏置、增益和校正矩阵。

装机时单独留出这些检查：

- 霍尔与磁钢的气隙变化会同时改增益和波形。轴承轴向窜动要小。
- 附近的钢板、喇叭磁钢会叠加一个近似恒定的磁场，表现为偏置。标定后不要再改周围结构。
- H1 上电后的机械角有 `Npp` 个可能。俯仰和横滚用重力找水平，航向用机械挡块或底座参考找零，找零完成前软行程限位不用这个角。

## 4. 方案二：磁编内环 + IMU 外环

磁编芯片读取轴端径向充磁磁铁，直接输出一圈内的绝对机械角。电角度由极对数换算，并用一次对齐消去安装偏移。

### 4.1 器件与机械

- 芯片选取带 SPI 的绝对式，分辨率 14 位量级即可，例如 AS5047P、MA732、MT6701。云台带宽远低于这个量化噪声。I2C 器件（如 AS5600）能用，但要确认读取延迟稳定且不超过几十微秒量级；读取抖动会直接变成换相角抖动。
- 磁铁为径向充磁圆柱（一个极对），粘在轴端中心。芯片数据手册中的气隙和径向偏心是硬指标，偏心大致要控制在 0.3 mm 以内，以所选芯片手册为准。
- 磁铁要离开转子磁钢足够远，避免电机自身漏磁把编码器磁场拉歪。中空轴云台尤其要检查这一点：云台电机极数多，漏磁不一定弱。
- SPI 用 DMA，与电流环同拍或按固定分频读取。打开 CRC 或奇偶校验。校验失败时保持上一拍角度，连续失败则停机。不要把跳变的角度送进 Park。

### 4.2 角度解算

```text
θm = (counts / counts_per_rev) * 2π          绝对机械角
θe = wrap(Npp * θm - θe_offset)               电角度
```

`θe_offset` 来自第 2.3 节。Npp 和磁铁充磁方向一起决定符号：若正 Iq 使 θm 减小，把公式中的 `Npp * θm` 取负，或者对调相线后重新对齐。只保留一种改法，并写进记录表。

机械角在一圈内绝对有效，上电即可做软限位和回中。多圈航向把圈数累加起来；上电那一圈的零点就是磁铁零点，装配时把磁铁零点转到关节零位附近，便于读数。

### 4.3 磁编标定

1. 确认 SPI 读数随手拨轴单调变化，转一圈计数回到同一点（允许 1 count 级回差）。
2. 确认气隙：芯片若提供磁场强度或自动增益（AGC）寄存器，其数值应落在手册推荐区。AGC 顶满说明磁铁太远或太弱。
3. 相序冻结后做第 2.3 节对齐，保存 `θe_offset`。
4. 验证正 Iq 使 θm 增加、相机陀螺符号与第 1 节约定一致。

磁编不需要椭圆校正。需要记录的是：磁铁与芯片的气隙、径向偏心检查结果、`θe_offset`、计数方向。

### 4.4 和 IMU 外环的接口

与方案一相同：电流环只用 θe，姿态环只用 IMU。机械角 θm 用于软限位、回中和航向跟随的关节参考。上电第一拍就可以用。

角速度环的速度反馈仍然取陀螺。磁编速度只用于监测和保护（例如关节角速度异常），不替代陀螺。

### 4.5 本方案的使用边界

适合：

- 三轴都要上电即知绝对关节角。
- 希望标定步骤短：对齐一次电角度偏移即可，没有模拟偏置和椭圆校正。
- 轴端有地方粘磁铁、放编码器板。

装机时单独留出这些检查：

- 磁铁胶固化后还会轻微蠕动。偏移标定放在胶干之后，跌落或重粘磁铁后要重做第 2.3 节。
- SPI 线离开电机相线，必要时在芯片侧串小电阻并加对地电容，避免 PWM 边沿造成偶发 CRC 错误。
- 读取延迟要固定。变化的延迟表现为随转速增大的换相误差；云台转速低，这项通常不主导，但仍把“不良帧保持上一拍”写进驱动。

## 5. 共用 IMU 外环

两套方案从这一节开始完全相同。IMU 安装在相机安装板上，位于横滚、俯仰、航向三个电机之后，和相机一起动。

### 5.1 器件与采样

- 陀螺噪声密度优先于量程。ICM-42688-P、BMI270 一类适合小云台。量程 ±500–±2000 °/s 足够。
- 陀螺内部输出 1 kHz 及以上，控制节拍取 1 kHz。加速度计用于慢速重力修正，有效带宽几赫兹即可。
- 轴向安装矩阵在装配后测定，不要依赖丝印假设。矩阵把 IMU 坐标变到云台 Roll / Pitch / Yaw。

### 5.2 姿态

俯仰和横滚有重力作绝对参考。航向在室内通常没有可用的磁参考，用陀螺积分，长期慢慢漂是预期行为，靠跟随环或用户回中处理。

可用一阶互补或 Mahony。互补的形式：

```text
每个轴先把陀螺积分得到姿态
俯仰、横滚再以时间常数 τ_g 把姿态拉向加速度计算出的重力倾角
τ_g 取 1–5 s。太大时上电水平收敛慢；太小时线加速度（走动、起飞）会把水平面拉歪
```

加速度模长偏离 1 g 较多时，降低本拍修正增益或暂停修正。

上电静止约 0.5 s，估计陀螺零偏并减去。之后只在确认三轴陀螺都接近 0、且加速度稳定时缓慢更新零偏。

### 5.3 姿态角环

锁定模式（俯仰、横滚默认如此）：

```text
e_ang = wrap_pi(θ_cmd - θ_hat)
ω_cmd = Kp_ang * e_ang
```

`θ_cmd` 水平锁定时俯仰、横滚给定为 0（或用户微调的安装误差角）。`Kp_ang` 决定姿态恢复的快慢，输出是角速度给定，单位与陀螺一致。

这一环只用 P。阻尼由角速度环提供。

### 5.4 角速度环

这是稳定手感的主环。反馈是相机陀螺，不是编码器速度。

```text
e_ω = ω_cmd - ω_gyro
Iq_ref = Kp_ω * e_ω + Ki_ω * ∫e_ω dt + Kd_ω * d(e_ω_f)/dt
```

- `e_ω_f` 是轻微低通后的误差，只送给 D。云台优先把 D 保持为 0，用 PI 完成稳定。D 直接作用在原始陀螺上时，电机容易出现高频嘶声。
- 积分抗饱和：Iq 已经顶到限幅且误差还在推同一个方向时，停止积分。
- 陀螺低通从 80–150 Hz 起试。截止低，噪声小，相位滞后大，高增益时容易振；截止高则相反。
- 每个机械轴一套增益。俯仰通常负载最大，三轴不要共用同一组数。

力矩到电流：`Iq_ref = τ / Kt`。不知道 Kt 时，直接把角速度环输出定义为 Iq，限幅设为电机持续电流。

### 5.5 跟随

航向经常需要慢慢跟上底座，俯仰和横滚保持锁定。

- 底座上如果有第二颗 IMU：取底座航向角速度，乘跟随系数（0–1）加到航向 `ω_cmd` 上，或把底座航向角低通后作为航向 `θ_cmd`。
- 没有底座 IMU 时：用关节机械角相对“上电零点或用户设定的中位”的偏差，经一个很慢的低通，作为航向角度给定。方案二的 θm 可以直接用。方案一的 H1 必须等找零完成后再用。

跟随要慢，时间常数从 0.3–1 s 起。跟随太快会把人手的抖动送进相机。

### 5.6 轴向符号标定

电流环和电角度已经按第 2.3 节校准之后：

1. 只打开一个轴的角速度环，增益放低。
2. 用手快速正向拨动相机。陀螺读数应为正，电机应产生反向力矩把相机拉回。
3. 若电机顺着拨动方向加速，把该轴 `Iq_ref` 的符号取反，或把该轴陀螺符号取反。两处只改一处。
4. 三轴分别做完，再三轴同时开。耦合大时检查 IMU 轴向矩阵和机械轴是否垂直，先修机械和矩阵，再加增益。

## 6. 两方案对照

| 项目 | 方案一 线性霍尔 | 方案二 磁编 |
| --- | --- | --- |
| 传感器输出 | 两路模拟电压 | 绝对计数（SPI） |
| 换相用的电角度 | H1 直接得到；H2 由机械角乘 Npp | 机械角乘 Npp 再减偏移 |
| 上电机械绝对角 | H1 有极对数模糊；H2 一圈内绝对 | 一圈内绝对 |
| 标定 | 偏置、增益、椭圆校正，再加电角度偏移 | 电角度偏移 |
| 主要误差来源 | 偏置温漂、气隙、外界恒定磁场、PWM 串扰 | 磁铁偏心、气隙、电机漏磁、SPI 坏帧 |
| 外环 | 相机 IMU，角速度环输出 Iq_ref | 与左栏相同 |
| 软限位和回中 | H2 上电可用；H1 先找零 | 上电可用 |

两种方案都用 IMU 做稳定外环，都用角度传感器做零速换相。磁编的标定步骤更少，上电就有绝对关节角。线性霍尔器件更少，H1 还能直接给出电角度；模拟标定和绝对机械角要按第 3 节处理。

## 7. 调试顺序

每个轴单独完成 1–6，再三轴合调。

1. 相线、采样极性、传感器读数方向。确认角度连续，没有饱和或 CRC 错误。
2. 测 R、L、Npp，写入记录表。按第 2.2 节算电流 PI。
3. 方案一先做霍尔偏置、增益和椭圆校正。
4. 第 2.3 节电角度对齐。验证正 Iq 使角度增加。
5. 电流阶跃：Iq 从 0 到 20% 持续电流，电流在 1 ms 量级跟上，没有持续振荡。
6. IMU 矩阵和陀螺符号（第 5.6 节）。
7. 角速度环：Kp 从很小加到轻敲相机后出现轻微振荡，再退回 30%–50%。然后加 Ki，直到不平衡负载下相机能停住，且没有秒级的来回摆。D 保持为 0，除非 PI 已经到位仍压不住某个振荡。
8. 姿态角环：加 Kp_ang，水平能拉住，阶跃给定不来回晃。若晃，先降 Kp_ang，再略增角速度环 Kp。
9. 航向跟随放在最后，从慢时间常数加起。
10. 三轴同时工作，检查一个轴的阶跃是否明显带动另外两轴。带动大时查机械正交和 IMU 矩阵。

保护：

- 相电流超过设定峰值立即关断 PWM。
- 角度传感器坏帧连续超过设定次数（例如 1 ms 内）关断。
- 关节软限位用机械角，方案一 H1 在找零完成前只允许较小的调试电流。

## 8. 运行时数据

调试和以后复查，每次记录至少留下这些量，采样 1 kHz 即可：

- 三相电流或 Id、Iq、Iq_ref
- θe、θm、角度传感器故障标志
- 三轴陀螺、融合后的姿态、ω_cmd
- 母线电压

文件名带日期和轴号。增益或偏移改动时在记录表里加一行，不覆盖旧行。
