# 欣易联 WiFi 模块结论

记录日期以仓库提交为准。对象是照片中的欣易联模块：屏蔽罩丝印 `ESP8285H16`，2.4 GHz，白插座 `DC5V / RXD / TXD / GND`，底边焊盘 `GND TX RX IO0 RST 3V3`。社区里同外观、同配网方式的电源模块型号是 **XY-WFPOW**。

## 模块本身

- 芯片是乐鑫 ESP8285（和 ESP8266 同一套指令集），H16 一般对应 16 Mbit（2 MB）片内 Flash。动手前用 `esptool flash_id` 核对容量。
- 晶振按乐鑫参考设计为 26 MHz。
- 白插座供 5 V，WiFi 启动时电源芯片要能稳定给出至少 300 mA。串口是 3.3 V TTL。
- 成品引脚和手头那份 `ESP31A_Module_V1` 参考图不是同一套按键接法：

| 功能 | 成品模块 |
|---|---|
| 与电源通讯 | GPIO1 = TX，GPIO3 = RX |
| 状态灯 | GPIO2，低电平点亮 |
| 配网键 | GPIO4，按下接 GND |
| 下载模式 | 底边 IO0 对 GND 再上电。配网键不是 GPIO0 |

参考图把按键放在 GPIO0 上。照那张图做，原厂程序认不出配网键，按住上电还会进下载模式。

配网：上电默认 Touch；失败则长按按键 5 秒以上进入 AP，热点名 `Sinilink Product`，密码 `12345678`。外网走欣易联的服务器。

和电源之间的协议是 Modbus RTU，功能码 `0x03`、`0x06`、`0x10`。寄存器见 [modbus-v2.1.md](modbus-v2.1.md)。`0x0030`–`0x0034` 是模块写给电源的主机类型、配网状态和 IP，供面板显示。`MASTER = 0x3B3A` 表示 WiFi。

## 原厂固件

能绑定欣易联 App 的是模块里的原厂程序，不是芯片封装。ESP8285 或 ESP8266 颗粒只要 Flash 容量够、26 MHz 晶振、引脚和射频与成品一致，把已购模块的整片 Flash 备份烧进去，App 可以把它当成新设备绑定。MAC 在芯片 eFuse 里，每颗不同。ESP32 不能跑这份固件。

公开渠道没有这份电源固件，也没有可编译源码：

- 官网能下的是 App 和电脑客户端，不是模块固件。安卓包：<http://www.sinilink.com/release.apk>。电脑客户端：<http://www.sinilink.com/download/tools/Sinilink-Setup.exe>。文档站：<http://doc.sinilink.com/tech-docs.html>。
- <http://www.sinilink.com/download/gujian/WFTX-V1.3.6.bin> 存在，但是温控器 XY-WFTX 的 V1.3.6（约 544 KB）。不能当作电源模块固件。
- 可编译的公开工程是替代固件，进 Home Assistant 或自带网页，不能绑定欣易联 App：
  - <https://github.com/framenic/sinilink-modbus>
  - <https://github.com/creepystefan/ESPhome-Sinilink-XY-WFPOW>

原厂程序没有独立烧录包。自用时从已买模块整片读出再写入；不要把已经配过网的同一份备份同时跑在两块板上。

## 不再走这条路的原因

原厂方案绑死欣易联 App 和他们的云，源码不公开，裸片还要自己做射频。后面的电源自己设计主控和 PCB，芯片不限于 ESP8285。联网改用板上的 ESP32 网关，手机和电脑直接访问自己的设备。做法见 [联网方案.md](联网方案.md)。
