# 电源 Modbus RTU 寄存器（V2.1）

这是自研电源从机要实现的约定，整理自手头的《Modbus 通讯协议》V2.1。商用 XY 电源有同一张表的变体，电流和功率的小数位不完全一样。自己做从机时以本文为准，网关和面板都按这里换算。

## 链路

| 项目 | 约定 |
|---|---|
| 协议 | Modbus RTU |
| 从机地址 | `0x01`（寄存器 `0x0018` 可读回；改地址后下次上电再生效） |
| 格式 | 8 数据位，无校验，1 停止位 |
| 波特率 | 固定 115200。文档里的 9600 只是在说明 3.5 字符帧间隔，不是本机波特率 |
| 功能码 | `0x03` 读保持寄存器，`0x06` 写单个，`0x10` 写多个 |
| 寄存器宽度 | 16 位，线上高字节在前 |
| CRC | 标准 Modbus CRC-16，多项式 `0xA001`，初值 `0xFFFF`，低字节先发 |
| 帧间隔 | 一帧之内不要插入超过 3.5 字符时间的停顿 |

`0x03` 的应答以文档末尾的例子为准：地址、功能码、**字节数**、数据、CRC。正文里那张“应答里带起始地址”的表是错的。

物理层是 3.3 V TTL。电源主控如果是 5 V 器件，进 ESP32 的 RX 要做电平转换，两边共地。

## 缩放

原始值是无符号 16 位整数。物理量 = 原始值 / 10^小数位。

| 小数位 | 含义 | 例子 |
|---|---|---|
| 2 | 0.01 | 24.00 V = `0x0960`（2400） |
| 3 | 0.001 | 1.500 A = `0x05DC`（1500） |
| 1 | 0.1 | 温度、过功率门限 |
| 0 | 整数 | 开关、计数、小时 |

文档例 3 把 `0x05DC` 写成 15.00 A。按 3 位小数，这是 **1.500 A**。

## 运行寄存器 `0x0000`–`0x001E`

| 地址 | 名称 | 小数位 | 单位 | 读写 | 说明 |
|---|---|---|---|---|---|
| `0x0000` | V-SET | 2 | V | 读写 | 输出电压设定 |
| `0x0001` | I-SET | 3 | A | 读写 | 输出电流设定 |
| `0x0002` | VOUT | 2 | V | 只读 | 输出电压 |
| `0x0003` | IOUT | 3 | A | 只读 | 输出电流 |
| `0x0004` | POWER | 2 | W | 只读 | 输出功率 |
| `0x0005` | UIN | 2 | V | 只读 | 输入电压 |
| `0x0006` | AH-LOW | 0 | mAh | 只读 | 输出容量低 16 位 |
| `0x0007` | AH-HIGH | 0 | mAh | 只读 | 输出容量高 16 位 |
| `0x0008` | WH-LOW | 0 | mWh | 只读 | 输出能量低 16 位 |
| `0x0009` | WH-HIGH | 0 | mWh | 只读 | 输出能量高 16 位 |
| `0x000A` | OUT_H | 0 | h | 只读 | 本次输出小时 |
| `0x000B` | OUT_M | 0 | min | 只读 | 本次输出分钟 |
| `0x000C` | OUT_S | 0 | s | 只读 | 本次输出秒 |
| `0x000D` | T_IN | 1 | °C/°F | 只读 | 内部温度 |
| `0x000E` | T_EX | 1 | °C/°F | 只读 | 外部温度 |
| `0x000F` | LOCK | 0 | — | 读写 | 0 未锁，1 面板锁定 |
| `0x0010` | PROTECT | 0 | — | 读写 | 保护状态，见下表。写 0 只清除锁存原因 |
| `0x0011` | CVCC | 0 | — | 只读 | 0 恒压，1 恒流 |
| `0x0012` | ONOFF | 0 | — | 读写 | 0 关输出，1 开输出 |
| `0x0013` | F-C | 0 | — | 读写 | 0 摄氏，1 华氏 |
| `0x0014` | B-LED | 0 | — | 读写 | 背光 0–5，0 最暗 |
| `0x0015` | SLEEP | 0 | min | 读写 | 息屏时间 |
| `0x0016` | MODEL | 0 | — | 只读 | 产品型号编码，自研自定义 |
| `0x0017` | VERSION | 0 | — | 只读 | 固件版本 |
| `0x0018` | SLAVE-ADD | 0 | — | 读写 | 从机地址 |
| `0x0019` | BAUDRATE_L | 0 | — | 只读 | 固定读回 `6`（115200）。不要在运行中改波特率 |
| `0x001A` | T-IN-OFFSET | 1 | °C/°F | 读写 | 内部温度修正 |
| `0x001B` | T-EX-OFFSET | 1 | °C/°F | 读写 | 外部温度修正 |
| `0x001C` | BUZZER | 0 | — | 读写 | 0 关，1 开 |
| `0x001D` | EXTRACT-M | 0 | — | 读写 | 写入 0–9 调出对应数据组 |
| `0x001E` | DEVICE | 0 | — | 读写 | 设备状态，自研自定义 |

`AH`、`WH` 都是高 16 位在前拼成 32 位：`(HIGH << 16) | LOW`。

保护状态 `PROTECT`：

| 值 | 含义 |
|---|---|
| 0 | 正常 |
| 1 | OVP 输出过压 |
| 2 | OCP 输出过流 |
| 3 | OPP 输出过功率 |
| 4 | LVP 输入欠压 |
| 5 | OAH 容量到限 |
| 6 | OHP 输出时间到限 |
| 7 | OTP 过温 |
| 8 | OEP |
| 9 | OWH 能量到限 |
| 10 | ICP 输入过流 |

清除保护：写 `PROTECT = 0`，再写 `ONOFF = 1` 才会重新打开输出。设定电压高于当前过压门限时，从机应直接拒绝或先锁存 OVP，不要把输出抬上去。

## 数据组 M0–M9

每组 14 个寄存器，布局与 M0 相同。正文写“起始地址 = `0x0020 + 组号 * 0x0010`”，又举例“M3 = `0x0050 + 3 * 0x0010` = `0x0080`”。寄存器表里的参数块从 `0x0050` 开始，和例子一致，和 `0x0020` 那个公式不一致。

自研从机采用表和例子：

```
组 N 的基地址 = 0x0050 + N * 0x0010
```

| 组 | 基地址 | 角色 |
|---|---|---|
| M0 | `0x0050` | 上电默认调用的一组。写这里立即作用于保护门限和上电开关 |
| M1 | `0x0060` | 面板快捷组 |
| M2 | `0x0070` | 面板快捷组 |
| M3–M9 | `0x0080` 起，每组加 `0x0010` | 普通存储组。M9 在 `0x00E0` |

组内偏移：

| 偏移 | 名称 | 小数位 | 单位 | 读写 |
|---|---|---|---|---|
| +0 | V-SET | 2 | V | 读写 |
| +1 | I-SET | 3 | A | 读写 |
| +2 | S-LVP | 2 | V | 读写 |
| +3 | S-OVP | 2 | V | 读写 |
| +4 | S-OCP | 3 | A | 读写 |
| +5 | S-OPP | 1 | W | 读写 |
| +6 | S-OHP_H | 0 | h | 读写 |
| +7 | S-OHP_M | 0 | min | 读写 |
| +8 | S-OAH_L | 0 | mAh | 读写 |
| +9 | S-OAH_H | 0 | mAh | 读写 |
| +10 | S-OWH_L | 0 | 10 mWh | 读写 |
| +11 | S-OWH_H | 0 | 10 mWh | 读写 |
| +12 | S-OTP | 1 | °C/°F | 读写 |
| +13 | S-INI | 0 | — | 读写 |

`S-INI`：0 为上电输出关闭，1 为上电输出打开。自研默认 0，并且掉电保存。

M0 的电压、电流与 `0x0000`、`0x0001` 保持同一数值。写 M1–M9 只改存储，不改当前输出，直到 `EXTRACT-M` 调出该组。

## WiFi 显示寄存器 `0x0030`–`0x0034`

给面板显示用。没有屏可以不实现。ESP32 连上路由器后周期写入。

| 地址 | 名称 | 约定 |
|---|---|---|
| `0x0030` | MASTER | `0x3B3A` 表示网络主机是本机 ESP32 |
| `0x0031` | WIFI-CONFIG | 0 无，1 一键配网，2 AP 配网 |
| `0x0032` | WIFI-STATUS | 0 未联网，1 已连路由器，2 本机服务已就绪 |
| `0x0033` | IPV4-H | IP 前两字节。192.168 写成 `0xC0A8` |
| `0x0034` | IPV4-L | IP 后两字节。1.8 写成 `0x0108`，即 192.168.1.8 |

原协议里的状态值 3、4 是欣易联 Touch/AP。自研网关只用 0、1、2。

## 已核对的报文

CRC 按标准算法算过，和文档例子里的线上字节一致。

读输出电压和电流（`0x0002` 起 2 个寄存器）：

```
主机  01 03 00 02 00 02 65 CB
从机  01 03 04 01 F4 05 DC B8 F4
```

从机数据表示 5.00 V、1.500 A。

把电压设为 24.00 V：

```
主机  01 06 00 00 09 60 8F B2
从机  01 06 00 00 09 60 8F B2
```

同时设 24.00 V 和 1.500 A：

```
主机  01 10 00 00 00 02 04 09 60 05 DC F2 E4
从机  01 10 00 00 00 02 41 C8
```

从机对非法地址、非法数值、只读寄存器的写操作返回标准异常帧（功能码最高位置 1）。电压、电流、保护门限在从机里再做一次上下限检查，网关检查不能代替这一层。
