# 001Diy

自研电源的联网记录：手机和电脑在同一套参数上读写电压、电流和状态。

| 文档 | 内容 |
|---|---|
| [联网方案](docs/联网方案.md) | 局域网里的硬件分工、网页接口、官方示例链接和 PCB 要点 |
| [远程操作](docs/远程操作.md) | 人在家里、电源在公司时如何打开同一个网页和 Modbus TCP |
| [Modbus 寄存器](docs/modbus-v2.1.md) | 按手头协议整理的从机寄存器、缩放和已核对的报文 |
| [欣易联模块结论](docs/欣易联模块结论.md) | XY-WFPOW / ESP8285 原厂固件能不能用、公开链接查到哪一步 |

当前采用的做法：电源主控做 Modbus RTU 从机，板上 ESP32 做网关。同一局域网里用网页和 Modbus TCP。人在公司网络之外时，用 Tailscale 访问这台电源的局域网地址，不把网页和 502 端口映射到公网。不使用欣易联原厂固件。
