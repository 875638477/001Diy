# 001Diy

自研电源的联网记录：手机和电脑在同一套参数上读写电压、电流和状态。

当前采用的做法：电源主控做 Modbus RTU 从机，板上 ESP32-S3 做网关。同一局域网里用网页和 Modbus TCP。人在家里时，用已有的 ThingsCloud 账号绑定这块 ESP32-S3，由云下发电压、电流和开关。涂鸦账号保留到要进 Smart Life 或量产时再用。不使用欣易联原厂固件，也不把网页和 502 端口映射到公网。
