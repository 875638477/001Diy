自研电源的联网记录：手机和电脑在同一套参数上读写电压、电流和状态。

| 文档 | 内容 |
|---|---|

当前采用的做法：电源主控做 Modbus RTU 从机，板上 ESP32 做网关。手机和电脑打开网页，电脑也可以走 Modbus TCP。不使用欣易联原厂固件。
